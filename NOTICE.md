公开仓库只复制许可明确且保留署名的图片。商家、评测与官方产品图若未取得再分发许可，
保留来源索引并由访客浏览器直接请求外站预览，不在仓库复制图片。预览与来源链接并不表示源站内容已采用本项目许可证；加载情况取决于原站与访客网络。

Downloaded image responses are preserved byte-for-byte. Some source servers
already supplied resized images. Preview thumbnails were resized and, where
needed, composited onto white; those derivatives keep the image's own license.
Both the gallery and attribution file identify these changes. A copy of the
source license metadata is retained in `data/media-manifest.json`.

Historical identification follows source labels and visual checks, not a
collector authentication service. Refurbished bodies, swapped skins, modified
film backs and uncertain regional aliases may appear in the reference records.
Counts distinguish catalog names from independent camera-body designs.

If an attribution or model assignment is wrong, open an issue with the model ID,
image source and supporting evidence. Corrections can update or remove the
affected material without replacing unrelated records.
