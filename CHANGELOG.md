# Changelog

## 0.1.0 — 2026-11-01

- Publish the source-linked catalog: 378 names / versions in 16 historical families.
- Include 151 openly licensed photographs with per-image author, source, license and modification notices.
- Preserve 1,207 photo references, representing 1,206 distinct images; material without verified redistribution permission is linked only.
- Provide offline HTML browsing, family/name/view filters, source-only records, missing-view lists and keyboard navigation.
- Add a standard-library build, integrity validation, contribution guidelines and optional GitHub Pages deployment workflow.
- Retain the six missing-photo entries and explicitly distinguish regional/special-version names from distinct camera bodies.
